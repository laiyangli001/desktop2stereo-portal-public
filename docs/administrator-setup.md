# 创建系统管理员

系统没有默认管理员账号。普通用户通过网站注册，系统管理员通过首次安装或受限的服务器命令建立。

## 新网站首次安装

1. 按 [README](../README.md#首次安装) 准备空数据库和 PHP 环境。
2. 在服务器项目目录运行 `php bin/install-token.php` 生成一次性安装用令牌，并在 `/install` 填写令牌。令牌只用于安装，不是后台密码。
3. 在安装页填写管理员用户名、管理邮箱及独立的强密码。管理员密码至少 14 个字符。
4. 安装向导建立数据库、创建具备全部权限的首个管理员并锁定安装入口。完成后通过 `/admin/login` 登录。

已有数据的站点直接使用现有后台或下述命令行方式。安装向导要求目标数据库为空。

## 已有数据库，首次补建管理员

当管理员尚未创建或原管理员无法登录时，由有服务器权限的部署人员执行。CLI 使用单独的操作账号连接数据库。该账号需能写入管理员、权限和审计相关表。

1. 在受限的进程环境中配置 `D2S_ADMIN_DB_DSN`、`D2S_ADMIN_DB_USER`、`D2S_ADMIN_DB_PASSWORD`。确认连接的是该站点的数据库。
2. 从受限配置注入临时环境变量 `D2S_BOOTSTRAP_PASSWORD`。使用独立的新密码。
3. 在项目根目录执行以下命令，将用户名和邮箱换成实际值。

   ```bash
   php bin/create-admin.php --username=site-admin --email=admin@example.com --roles=superadmin
   ```

4. 命令成功返回 `admin_id`。退出或清理当前终端中的临时密码，再通过 `/admin/login` 登录。该命令创建新用户，用户名和邮箱必须未被占用。

## 增加员工或分配权限

已有管理员可以在「员工管理」`/admin/staff` 创建员工并按职责分配权限。客服、财务和内容人员可以分别使用对应角色。权限维护及其他部署事项见 [账户接口](accounts-api.md) 与 [部署说明](deployment.md)。
