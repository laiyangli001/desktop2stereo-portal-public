# 多软件授权接入（2026-11-16）

本文记录授权隔离、多商品交易及前后台多授权管理的本地实现和验证证据。真实渠道付款、各软件原生客户端及 P7 完整验收仍待完成，不代表可以切换生产。

## 客户端软件标识

- `POST /api/v2/client/login` 可增加字符串 `product`，如 `stereo_player`。缺省仍为 `desktop2stereo`，以兼容现有客户端。
- 每个账户每个软件各有一份权益、独立试用起点及当前会话。同一软件换机顶替旧会话，不顶替其他软件。
- 心跳/退出根据已认证 Token 解析软件，不采用请求体中的软件字段决定权限。
- `GET /api/v2/me/license`、`GET /api/v2/me/license/devices` 支持 `?product=stereo_player`。只读取当前网站登录账户。
- 网站退出指定软件会话的 POST 增加可选字符串 `product`，仍需 CSRF、设备摘要和会话版本。
- 设备身份登记仍为账户共享；当前会话独立保存设备公钥快照，另一软件在相同设备上使用不同公钥不会覆盖本会话心跳所用公钥。设备历史按该软件的签发记录和当前会话归属展示；只有从未持有其他软件的旧账号，默认软件才兼容显示旧的账户级设备历史。
- 已存在的权益不因商品下架自动撤权；未持有权益者只能为仍上架的商品开始试用。撤权仍走明确的权益状态和退款流程。

## 资源密钥配置

Desktop2Stereo 继续使用 `D2S_PARALLAX_CORE_KEY_HEX` 和 `D2S_PARALLAX_CORE_SHA256`。

其他软件分别使用 `D2S_PRODUCT_<软件标识的UTF-8字节的大写十六进制>_PARALLAX_CORE_KEY_HEX` 和同前缀的 `PARALLAX_CORE_SHA256`。例如 `stereo_player` 的前缀是 `D2S_PRODUCT_73746572656F5F706C61796572_`。编码避免连字符与下划线被归一化为相同变量名。

每个软件应配置自己的资源密钥和资源摘要；缺失时拒绝签发，不回退 Desktop2Stereo 密钥。密钥只通过受限环境注入，不写入源码、日志或普通商品介绍。ES256 公钥体系继续共用，签名载荷绑定软件和资源；客户端必须固定验证自己软件的 `product`，不能仅凭签名正确接受其他软件凭证。

当前包装协议仍为既有 parallax-core v1；不同资源协议/不同客户端的实际联调仍须单独验收。服务端凭证配置与数据库迁移通过不等于真实客户端发布完成。

## 多商品交易与公开目录接入（本地链路通过）

- 报价按软件选择 CNY/USD 价格，订单只从服务端报价确定软件，不能被建单请求中的软件字段替换。履约升级/创建同一软件的权益；其他软件的权益不参与重复购买判断。
- 迁移 `0061_software_pending_orders.php` 将待支付唯一约束改为账号＋软件；钱包充值另占自己的名额。同一软件仍不允许同时占用两个待支付订单。
- 使用 `portal_product_prices` 作为报价价格来源。旧价格 API 写入默认软件的同一价格，并维护旧表镜像；后台商品页面改价会立即使该软件旧报价失效。
- 支付宝、微信及国际支付收银台继续检查总开关、单商品开关、上架状态和本软件权益；已创建订单的有效支付通知不受下架开关影响。微信收款、退款查询/申请及对账选择已扩展到独立软件，撤权仍依据履约记录绑定的软件。
- 公开 `/products` 按已发布介绍展示多个商品、图片和各自价格；关闭购买的商品仍可展示，无购买入口。购买链接携带商品标识，游客登录、主动确认政策后返回同一商品。返回目标使用严格白名单，拒绝外部链接、额外参数和保留充值标识。

## 前后台多软件授权与用户购买情况

- 用户授权页支持切换软件，展示全部持有的授权卡片、各软件独立状态/到期时间、当前会话和设备历史。下架但已持有的权益仍可查看和退出会话；浏览网页不开始试用。
- 后台用户列表按账号去重，显示软件数量、有效正式授权和有效试用数量，优先预览已购买软件名称。完整清单放在详情中，避免列表随软件数量无限增高。
- 软件筛选和授权类型必须匹配同一份权益；例如购买播放器、试用编辑器的账号，不会匹配“编辑器＋正式授权”。
- 用户详情列出全部软件授权，以及按软件、原币种分组的实付/退款/净额/最近付款记录；钱包充值不计入软件购买记录。后台销售统计包含所有软件，正式授权数与购买账号去重数分别计算。
- `POST /api/v2/admin/operations/users/<id>/client-session/logout` 需要 `users.manage`、管理员会话、同源 JSON 和 CSRF，提交 `product`、`device_hash`、整数 `session_version`。版本不符返回409，只读人员不可操作。删除指定软件会话和审计同事务，审计失败全部回滚，不影响其他软件。
- `GET /api/v2/me/license` 保留指定软件的 `license`，增加全部 `licenses`；设备接口同时提供 `products` 和 `selected_product`。响应不暴露会话 Token 哈希或设备公钥。
- 固定 UI 的新增文案覆盖11种登记语言。授权页隐藏控件使用明确的作用域样式，避免布局样式覆盖 `hidden`。
- 本轮已验证：多软件管理服务/API 35项及浏览器27项、后台69项、原授权页浏览器35项及网页不创建权益、内容76项、原授权 MySQL/HTTP/并发59项、钱包退款60项、验收运行器41项、目录17项及 ICU 53项。桌面和手机截图已检查；未调用真实支付或翻译服务。
