# 网站法律公示与文本清单

日期：2026-11-13；适用项目：Desktop2Stereo 网站与软件在线服务。本清单用于开发、上线前复核和年度检查，不替代针对实际经营资质的法律意见。

## 官方依据

- 《中华人民共和国个人信息保护法》：告知、同意、公开处理规则，以及查阅、复制、更正、补充、删除、限制处理和注销账户等权利。https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm
- 《中华人民共和国电子商务法》第十五条：首页显著位置持续公示营业执照和经营相关行政许可信息或其链接。https://www.samr.gov.cn/wljys/gzzd/art/2023/art_3e75434c954b4cb9bd14867dacff26d1.html
- 《网络交易监督管理办法》第十二条：公示经营者主体信息或许可信息链接。https://www.samr.gov.cn/wljys/gzzd/art/2023/art_09c394cce74f424a8d82dbc4811a11ec.html
- 《互联网信息服务管理办法》及工信部网站备案说明：经营性服务许可、非经营性服务备案。https://www.miit.gov.cn/datainfo/fgk/gytxyxxhfg/xzfg/art/2020/art_44595811ff9a42b9b073386046905103.html
- 工信部 ICP/IP地址/域名信息备案管理系统：https://beian.miit.gov.cn/
- 全国互联网安全管理服务平台：https://beian.mps.gov.cn/

## 页面与公示状态

| 项目 | 本地实现 | 上线前要求 |
|---|---|---|
| ICP备案号及工信部链接 | 首页/法律页脚动态展示 `d2s.site`、`d2s.top` 备案号并链接工信部系统 | 核对实际主体、域名和号码完全一致 |
| 公安联网备案号及链接 | 支持后台配置编号和 `beian.mps.gov.cn` 查询链接；未取得时隐藏 | 完成备案后填写真实编号，不得使用占位数字 |
| ICP经营许可证（如适用） | 支持后台配置，未配置时隐藏 | 根据实际经营模式和主管部门要求确认是否需要并填写 |
| 营业执照/主体信息 | `/business-license` 展示运营主体、备案号和执照图片 | 核对执照、公司全称、统一社会信用代码和页脚主体一致 |
| 用户协议 | `/terms`，中英文，注册勾选并保存版本同意快照 | 运营负责人/法律顾问确认退款、软件许可和争议条款 |
| 隐私政策 | `/privacy-policy`，含信息范围、用途、保存、服务商、用户权利、Cookie | 与实际服务商、备份周期、支付渠道和工单删除流程一致 |
| 登录 IP 与安全历史 | 隐私政策、用户协议和登录页说明用途、范围、366天最低留存、独立留存账号清理及“不作为身份/居住地/授权证明”边界 | 上线前复核网络安全日志的必要性、实际调度、告警、备份保留和恢复后防回流 |
| 法律声明 | `/legal-statement`，含产品信息、外部链接、第三方组件和责任边界 | 与软件实际兼容性、第三方许可证和售后政策一致 |
| 联系我们 | `/contact`，邮箱、私密工单、注册地址指向营业执照 | 确保邮箱长期有效，建立首答和投诉台账 |
| Cookie说明 | 隐私政策章节及 `docs/cookie-statement.md`；当前仅必要Cookie | 引入广告/分析/非必要存储前更新并取得所需同意 |
| 注册主动同意 | 注册页必须勾选用户协议和隐私政策；服务端读取当前版本并写只追加同意快照 | 每次政策重大变更重新告知并在需要时取得同意 |
| 投诉/权利请求 | 私密工单 + 邮箱；目标10个工作日首次回复 | 建立受理、核验、处理、答复和留存记录 |
| 未成年人 | 协议和隐私政策明确主要面向成年人 | 结合实际运营评估是否需要监护人机制 |
| 年度复核 | 本清单和 SEC-001 提供复核项 | 业务、服务商、备案、许可证或法律变化时同步更新 |

## 当前不能宣称已完成的事项

1. 尚未提供公安联网备案号，因此页面不会伪造或展示该项。
2. 是否需要 ICP 经营许可证尚未由实际经营模式及主管部门确认；当前字段为空并保持隐藏。
3. 用户协议、隐私政策和法律声明均需在正式上线前由运营负责人及合格法律顾问复核并填写实际生效日期。
4. 页脚备案号来自项目现有配置；上线前必须在工信部备案系统核对主体、域名和编号。
5. 生产部署、实际服务商配置、真实支付/邮件短信和制度签署尚未验收。

## 配置入口

管理员进入 `/admin/content` 配置站点名称、运营主体、政策版本/生效日期、ICP备案号、ICP经营许可证、公安备案号和查询链接。运行账号与管理员操作继续受权限、CSRF和审计控制。
